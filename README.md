# Sweet Treats Bakery - Part 3 Final Submission

Welcome to the **Sweet Treats Bakery** web project repository! This repository contains the complete responsive website with JavaScript interactivity, form validation, and Search Engine Optimization (SEO).

## 🚀 Part 3 Features & Additions
- **Interactive FAQ Accordion:** Implemented collapsible accordion functionality on `about.html` using Vanilla JavaScript.
- **Dynamic Search Filtering:** Added real-time product search and filter capability on `products.html`.
- **Form Validation & Processing:** Enhanced `enquiry.html` and `contact.html` with client-side field validation and custom response handling.
- **On-Page & Off-Page SEO:** Configured meta titles, descriptions, open keywords, image alt attributes, `robots.txt`, and `sitemap.xml`.
