 Project Overview
Sweet Treats Bakery is a web development project designed to establish an online presence for a local artisan bakery. The website provides customers with menu access, company background, contact details, and a custom cake order enquiry system.

---

 Website Goals and Objectives
Promote Brand Visibility: Showcase artisan breads, pastries, and custom cake options.
  Streamline Customer Enquiries: Provide an online form for customers to request custom cake quotes.
  Enhance User Experience: Ensure intuitive navigation across all main pages.

---

 Key Features and Functionality
Global Navigation Header: Uniform navigation links (`Home`, `About Us`, `Products`, `Enquiry`, `Contact Us`) present on every page.
  Interactive Enquiry Form: Text inputs, dropdown selections, and text areas for custom orders.
  Structured Directory Architecture: Clean division of HTML files, styles (`css/`), scripts (`js/`), and media assets (`images/`).
